# 🧰 智能工具箱

一个完全自定义的在线工具箱，支持云存储和多用户独立使用。

## 🌐 在线访问
- 主站：https://你的用户名.github.io/你的仓库名/
- 备用链接：https://你的自定义域名.com

## ✨ 功能特点
- ✅ 完全自定义的工具箱布局
- ✅ 云存储支持（数据永不丢失）
- ✅ 多用户独立使用
- ✅ 拖拽排序模块和工具
- ✅ 多种布局选择
- ✅ 自定义背景和主题
- ✅ 搜索引擎集成
- ✅ 响应式设计

## 📱 使用方法
1. 访问网站
2. 点击左上角"登录/注册"按钮
3. 创建新账户或登录
4. 开始自定义你的工具箱

## 🔒 数据安全
- 所有用户数据独立存储
- 采用Supabase安全认证
- 数据加密传输
- 定期自动备份

## 🔧 技术栈
- 前端：HTML5, CSS3, JavaScript
- 云存储：Supabase
- 部署：GitHub Pages
